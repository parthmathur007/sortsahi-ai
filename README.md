# SortSahi AI

AI-powered waste segregation and awareness platform.

## Project goals

- Identify waste items using text or image input.
- Provide appropriate waste-segregation and disposal guidance.
- Support GreenScore and Daily Waste Challenge features.
- Deploy the application using eligible AWS services.

## Project structure

The final folder structure will be agreed upon by the team before application code is integrated.

## Technology stack

- Frontend: Next.js (planned)
- Backend: Python API (planned)
- Machine learning: To be confirmed with the ML team
- Hosting: AWS Amplify for the frontend; backend hosting to be confirmed

## Development workflow

1. Each member works on a separate feature branch.
2. Changes are submitted through pull requests.
3. The team reviews changes before merging.
4. Secrets and API keys must never be committed.
5. Integration and deployment must be tested before the final demo.

## Configuration

Use `.env.example` as the reference for required environment variables. Create a local `.env` file for development when needed. Never commit real credentials.

## Deployment

Deployment instructions and verified AWS architecture will be documented in `docs/deployment.md` after the application stack and AWS eligibility requirements are confirmed.
